# 音乐归齐与强调色修正

2026-09-10。

> 历史状态：2026-11-21 已随全部交互音效移除 `rhine-local-sound` 和 `SpectrumEnvelope.ignoreLocalSound`。本报告下列自身声音过滤说明与既有截图保留为历史验收记录，不按当前实现重写。

壁纸的短交互声音也可能进入 WE 系统频谱。播放本地音效时记录实际音符结束时间与 200ms 回传余量，在尚未形成音乐活动时忽略该时间内的新频谱活动；已有音乐继续响应。音乐强度为零时不驱动归齐。

归齐进度同时控制阵列与选中标签的强调程度，完全归齐时无强调色。暗色“仅选中强调”根据当前档案实际升降插值，新选中与归位副本均连续更新。

历史验证中，`scripts/check-local-sound.mjs` 复现未过滤时的假音乐起点，验证自身声音抑制、持续音乐起动与保留、信号丢失回落。该脚本已随本地点击滤波移除。原 Edge 1600×900 实际拖动与模拟宿主频谱检查记录了静音拖动 `flatten=0`、新旧档案强调色中间值、全部归齐无强调及恢复；截图与结果保留在 `verification/selection-state/`。当前 `scripts/check-selection-state.mjs` 改为验证拖动期间外部频谱持续生效，停止信号后回落。

用户本轮决定保留原版、连续频谱、层叠流波三种音乐律动供自行选择，默认原版。
