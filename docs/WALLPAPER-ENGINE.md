# Wallpaper Engine 本地构建

## 构建与本机预览

在 `RhineLabUI/` 根目录执行：

```sh
npm run build:wallpaper
node scripts/check-wallpaper.mjs
```

- **构建产物**：输出到 `release/wallpaper/`，以相对资源路径打包完整字体、GLB 模型、背景配乐、档案 TXT、图标与 [project.json](../wallpaper/project.json)（同时剔除网页专用 `update.html`、`manifest.webmanifest`、MP3 试听版及未带哈希的模型副本，并校验 `general.supportsaudioprocessing === true`）。
- **导入编辑器**：在 Wallpaper Engine 编辑器中仅导入构建后的 `release/wallpaper/` 目录（或本地副本目录，指向其中 `index.html`），不要导入整个源码仓库。
- **开发预览**：运行 `npm run dev -- --mode wallpaper --port 5176`，在浏览器中打开 `http://127.0.0.1:5176/` 预览壁纸端界面和工作台布局。

## 壁纸端现行能力

相比网页纯净画布模式，Wallpaper Engine 本地端额外开放完整桌面界面与宿主属性联动：

1. **双工作模式（`desktopmode`）**：
   - **桌面工作台（`workbench`）**：集成时间日期、三项今日事项（每日自动重置状态）、重要日程倒计时、系统正在播放媒体信息、番茄专注/休息计时与「波纹接力」小游戏，并提供 7 项独立界面元素显隐开关与「可用功能」开关。
   - **档案展示（`archive`）**：完整保留悬停标题浮层、右侧 2D 详情面板（查看记录、访问原作、收藏、下载 TXT），以及支持旋转、缩放、平移、分层拆解与手动清晰／磨砂切换的 360° 模型查看器。
2. **音乐与外部频谱律动**：
   - 保留「观测室」三轨循环背景音乐与独立开关／音量（见 [音频说明](../public/audio/README.md)），**已移除所有界面与交互音效**。
   - 支持读取 Wallpaper Engine 提供的系统 128-bin 音频频谱，在工作台模式下驱动三种律动方案（原版多层起伏、方案 A 左右连续频谱、方案 B 连续层叠流波），并支持律动期间自动静音壁纸配乐与独立「静止时呼吸」开关。
3. **画面、配色与性能优化**：
   - **界面配色**：原 `colortheme` 配色切换属性已移除，壁纸端固定为亮色暖焦糖调。
   - **画质与超级性能模式**：提供性能／原始／高／极高及 9 项参数可调的自定义画质，以及保留动态效果的「超级性能模式（`superperformance`）」。为规避部分 CEF 环境下 `<select>` 下拉崩溃问题，壁纸设置页内的画质切换按钮采用点击循环方式。
   - **HUD 与自定义壁纸**：提供 UI 鼠标曲面视差、全局屏幕效果（细颗粒、色散、暗角）、文字磨砂底、四边距偏移（−300～300 px）；支持关闭「启动时加载 3D」或随时通过左下角开关卸载 3D 资源并淡入自定义壁纸图片（可调上下遮罩范围）。

## 现行行为约定

- **直接进入阵列，统一磨砂质感**：壁纸端同样已移除早期的 2D 逐帧开机片头、Novecento 字体及进入详情磨砂变透明解密（总览与详情均保持磨砂卡匣，仅 360° 查看器保留手动清晰／磨砂开关）。
- **属性优先级**：每次启动以 Wallpaper Engine 宿主下发的属性为准；壁纸内部设置弹窗的修改仅对当前运行会话生效，不会反向回写宿主属性面板。
- **桌面输入提示**：在部分桌面壁纸环境下，系统宿主可能不会把方向键或鼠标滚轮转发给壁纸；推荐通过鼠标拖拽阵列与点击界面按钮操作。
- **当前可见性**：[project.json](../wallpaper/project.json) 当前设为 `visibility: "private"`，仅用于本机与自用测试，不包含旧版《明日方舟》创意工坊发布流程。

更多三维视觉与卡面参数见 [设计规范](DESIGN.md)。
