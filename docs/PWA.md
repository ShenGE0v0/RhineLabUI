# 主屏幕安装与离线使用

在支持安装网页应用的浏览器中打开你部署的 **DEEPDEMOS 档案库**。iPhone 或 iPad 可在 Safari 中选择「分享 → 添加到主屏幕」。其他平台可通过浏览器菜单安装。

安装后保持联网并进入档案阵列，浏览器会在后台准备模型、字体、音乐和档案等离线资源。清理网站数据或遇到浏览器回收缓存后，需要重新联网准备。

首次进入跟随系统的减少动态效果偏好。启用背景音乐时，点击入口或按 Enter 可解锁浏览器音频。音乐加载失败时可重试，或选择关闭音乐后进入阵列。

## 更新与恢复

如果浏览器仍显示旧版本，在同一站点打开 `/update.html` 并点击「更新并返回」。恢复页会联网下载和应用完整版本，保留当前浏览器中的收藏与偏好。

## 本地验证

运行 `npm run build` 和 `npm run preview`，再用浏览器打开预览地址。Service Worker 在 HTTPS 或 localhost 的生产构建中注册。网页部署的缓存规则见 [vercel.json](../vercel.json)。
