### 设计语言（核心原则）

1. **纯正无底设计，尽可能简洁（第一原则）**：所有前端浮层、轻提示（`#toast`）、状态标签与模型列表必须做到**零底色、零渐变散雾底衬、零光晕描边、零边框阴影卡片、零 hover/active 底色填充**；文字直接落在暖纸留白区，以字重、字色层级、聚光灯 `opacity` 衰减和唯一共享左侧 `2.5px` 炭黑（`#171410`）竖条传递状态（启用时由圆点对称展开为长条，切换行时沿纵轴弹性滑动，静置 `3.5s` 自动从上下两侧收起为小圆点留驻并可由交互唤醒；面板折叠时黑条先收成圆点再与图标同曲线协同飞升停靠于折叠图标正下方，展开时随图标回落后再对称伸展成长条，取消排序时则缩点淡出隐藏）。
   - **禁止回退**：`#toast` 不得使用深色/实色矩形底框、渐变散雾伪元素或阴影衬底；`.model-vote-row` 的 `:hover` 与 `[data-active="true"]` 必须保持 `background: transparent`。
2. **排版与空间叙事优先**：以字体字重、字距、位置与节奏传达层级，而非边框或容器包裹。
3. **统一动效语言**：`#toast` 入场/出场与右上角标题（`#clean-archive-title`）、封面预览、模型票数面板共用 `src/mist-etch-dissolve.ts` 的 8 层微蚀刻 SVG `<mask>` + 光学柔焦位移消融（入场 `720ms` / 出场 `820ms`）。

### 本地预览

在 `RhineLabUI/` 执行 `npm run dev -- --port 5173`，打开 [普通启动](http://127.0.0.1:5173/) 或 [档案总览直达](http://127.0.0.1:5173/?scene=archive)。验证冷启动入场时使用普通启动入口；验证外部 JSON 启动注入可使用 `/?data=/api/demos.json`。
