# RhineLabUI 网页交接

## 2026-11-27 接手基线

本轮在 `b75ac81`（在 `8c4c189` 与 `50d3032` 之上已合入纯净态右上角方格溶解悬停标题、初版滚轮性能优化与非均匀列重基、40 份本地静态封面同源托管、外部/动态数据输入接口）之上，已完成以下五组优化与功能：

1. **全交互流畅度与卡顿消除**：修改 [scene.ts](../src/scene.ts)、[archive-visibility.ts](../src/archive-visibility.ts)、[archive-draw-coverage.ts](../src/archive-draw-coverage.ts) 与 [main.ts](../src/main.ts)——新增 `overviewFullCache`（12 槽 `1024×743`）、`hoverBadgeCache`（24 槽 `1024×96`），并将 `overviewHeaderCache` 降为 `1024×193`（均启用 `{ willReadFrequently: true }` 与完整纹理/Uniform 回收，其中 `overviewFullCache` 由 `invalidateOverviewFullCache()` 统一失效回收），彻底消除拖动/滚轮期间 `2048×1485` 全尺徽章同步上传造成的 Skia 停顿；用基于 `modelBounds` 与 `canvasRect()` 缓存的零分配包围盒射线替换 `pickCell()` 三角网格求交；设 `MIN_OUTGOING_SPAWN_LIFT = 0.035` 与离场池超限淘汰、`isDetailBadgeActive()` 门控 2K 详情徽章切换；[archive-visibility.ts](../src/archive-visibility.ts) 改为零分配 `Float64Array(38)` 比较，并缓存 DOM 节点与脏检查 `--detail-shade`。
2. **GPU 降载与失焦／静止 0% 停帧复用**：修改 [scene.ts](../src/scene.ts)、[shared-depth.ts](../src/shared-depth.ts)、[quality-renderer.ts](../src/quality-renderer.ts)、[render-quality.ts](../src/render-quality.ts)、[appearance.ts](../src/appearance.ts)、[archive-slot-underlight.ts](../src/archive-slot-underlight.ts)、[main.ts](../src/main.ts)、[quality-settings.ts](../src/quality-settings.ts)、[DESIGN.md](DESIGN.md) 与 [check-startup-motion.mjs](../scripts/check-startup-motion.mjs)——阴影仅由单一 `shadowSource` 投射；剔除背景堆叠实例的 `role === "card"` 与背面隐藏 `shell`/`frame` 网格，同时以 `CardAppearance.register(name, mat, mat)`（配合 [appearance.ts](../src/appearance.ts) `low === high` 跳过插值且避免重复 `dispose`）保障选中卡与返还卡外层印刷面/背板不出现 dither 丢弃；按从前到后设置不透明 `renderOrder` 并关闭阵列玻璃 `clearcoat`；仅为纯净模式下未修改的默认 `"original"` 预设启用 `useCleanEcoBudget`（`2,073,600` px 1080p 级像素预算与 `1024` 阴影分辨率，切换到 `"high"` / `"ultra"` 或自定义参数完整解锁 `829` 万像素与自选阴影）；总览禁用 `SharedDepthBokeh`（已在 `warmUpOverview()` 预热着色器防止首次打开详情编译卡顿）并在详情端为 `SharedDepthBokeh` 合焦像素增加早退；快速拖动/离场期间隔帧更新阴影（配合 `shadowStale` + `webglcontextrestored` 重置 `shadowTick`）；在 `scene.ts` 新增 `snapSpring()` 与指数插值/相机尾波截断，配合 [archive-slot-underlight.ts](../src/archive-slot-underlight.ts) 阈值收敛、缩短聚焦呼吸窗口（`2.5–7.5 s` / `15 fps`）及失焦 `20 fps` 快速过渡，使静置或切窗失焦约 `2.5–3.8 s` 后稳定进入 `RenderState` 100% 停帧复用（0 次 WebGL 绘制）。
3. **详情视角底边反光条与左下橙色渗光修复**：修改 [scene.ts](../src/scene.ts) 与 [archive-overview-look.ts](../src/archive-overview-look.ts)——为选中卡材质（`mode === "selected"`）引入 `overviewSelectedSlotProximity`（随 `lift: OVERVIEW_LIFT + 0.15 .. + 1.85` 抬出卡槽与 `detail` 平滑从 `1` 衰减至 `0`，并纳入 `RenderState`），同时将 `overviewAreaLight.intensity` 乘以 `(1 - detail)`；仅衰减槽位底部接触发光、左下角橙光混合与底边面光反射，保持总览入槽灯效 100% 不变以及详情卡片洁净的暖象牙白与文字图片对比度。
4. **入场过场隐藏右上角标题并在待选完毕后溶解显现**：修改 [block-dissolve-title.ts](../src/block-dissolve-title.ts)、[scene.ts](../src/scene.ts)、[main.ts](../src/main.ts)、[DESIGN.md](DESIGN.md) 与 [HANDOFF.md](HANDOFF.md)——`scene.ts` 暴露 `isIntroActive` 与 `onIntroChange`，`main.ts` 在启动加载与四阶段入场过场期间保持 `#clean-archive-title` 为空（`replayIntro()` 同步复位，直达 `?scene=detail` 或 `reducedMotion` 立即显示），待入场完成或被交互打断后再经 `BlockDissolveTitle` 以 `"" -> title` 左到右细方格溶解显现。
5. **右上角标题下方封面预览窗**：新增 [clean-cover-preview.ts](../src/clean-cover-preview.ts) 并更新 [main.ts](../src/main.ts)、[scene.ts](../src/scene.ts)、[style.css](../src/style.css)、[responsive.css](../src/responsive.css)、[DESIGN.md](DESIGN.md) 与 [HANDOFF.md](HANDOFF.md)——在 `#clean-archive-title` 正下方新增右对齐 `16:10` 非交互封面预览 `#clean-archive-cover`（桌面宽 `304 px`，紧凑与竖屏响应式收敛），使用双层异步解码 `<img>` 与加载令牌防竞态及快速连扫锁帧（`.is-settled`）；在启动加载、入场过场（含 `replayIntro()` 瞬时隐藏）、详情态与无可用封面时自动隐藏，总览待选就绪后随当前悬停或选中档案交叉淡入切换（独立于 `rollingText` 开关），并同步响应 `rhine.setCardPhoto()`（含 `null` 显式占位符防默认封面回填与控制字符/协议白名单校验）及外部数据集/布局重载。

*已提交基线 `b75ac81` 内含前序 4 项功能与基建（悬停标题方格溶解、初版滚轮优化与 `rowOrigin` 非均匀列重基、40 份本地同源封面与 PWA 预缓存、外部/动态数据输入接口）。*
